# المزايا والبنية

[English](../en/FEATURES.md) · [العربية](FEATURES.md)

Remotion هو الخط الزمني الرئيسي. مكوّنات React ومسارات GSAP المتوقفة والمربوطة بالإطار وتحويلات Three.js دوال حتمية في رقم الإطار والمدخلات.

```text
وصف أو نص مفرغ
  ← ShotGraph أو storyboard مراجع
  ← Style Profile وفهرس أصول
  ← توجيه 2D أو Three أو تسلسل Blender اختياري
  ← QA وموافقة بشرية
  ← رندر Remotion وتحقق FFprobe
```

## أساس الإنتاج

- ShotGraph للتوقيت والمسارات والانتقالات والمحرك.
- Style Profiles للألوان والخطوط والإيقاع والمساحات الآمنة.
- Asset Catalog للمصدر والترخيص، وتبقى الأصول `unknown` بلا دليل.
- QA يفحص schema والتوقيت والنص والأصول والتوافق.
- تتعطل الموافقة السابقة تلقائيًا عند تغير المحتوى.

## الحركة والنص

المكوّنات القابلة لإعادة الاستخدام في `src/motion` و`src/components` و`src/typography`. تشكيل العربية محفوظ والحركة على مستوى كلمة أو سطر. بنك Majed مثبت بإصدار محدد ومدقق ومنسوب لصاحبه.

## 3D والوسائط

الدعم يشمل `@remotion/three` وReact Three Fiber وDrei وRapier وpostprocessing. Blender يحتاج تثبيتًا خارجيًا محليًا. FFmpeg للتطبيع والقص والتصدير، وwhisper.cpp اختياري ومحلي.

## المهارات

تتضمن توجيه HASKA وتصميم الحركة وRemotion للإنشاء والـ markup والرندر والترجمة والخرائط والوسائط والاستوديو. أمرا Claude هما `/create-video` و`/audio-to-motion`.

## توافق Majed

المتاح: الحركات والأنماط والنص العربي ومفاهيم talking-head والمونتاج والأغلفة والنص خلف الشخص وEDL/OTIO. المستبعد: fal.ai المدفوع، النشر الاجتماعي غير المرخّص، التحديث الذاتي الخطر، الترويج، تعديل ملفات CapCut الداخلية وأدوات Vision الخاصة بـ macOS.

## الحدود

لا يخترع HASKA شاشات أو شعارات أو ادعاءات. لا خادم عام أو cloud backend أو قاعدة بيانات أو telemetry أو API مدفوع. CI لا يقيس الجودة البصرية أو السمعية ولا يختبر Windows GPU أو OptiX.
